# APMA3150-Midterm-Project
An application that rebuilds and improves upon the Interactive Hypothesis Testing App.
To see the published version of the app, [click here](https://hpb2gv-kevincha.shinyapps.io/MidtermProject-hpb2gv-jna6pw-wws2ns/).

## Setup
Clone the repository via:
```
git clone https://github.com/kevincha12/APMA3150-Midterm-Project
```

You will need the shiny library package, which can be obtained via:
```r
install.packages("shiny")
```
